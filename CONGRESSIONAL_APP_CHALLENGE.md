# Shelter Match - Congressional App Challenge 2024

## 🏆 Project Overview

**Shelter Match** is a comprehensive web application designed to connect homeless individuals with available shelter beds and job opportunities in Los Angeles. Built with modern web technologies, the app addresses the critical need for accessible, real-time information about shelter availability and employment opportunities.

## 🎯 Problem Statement

Los Angeles has one of the largest homeless populations in the United States, with over 75,000 individuals experiencing homelessness. The challenge lies in:

- **Information Gap**: Difficulty finding real-time shelter availability
- **Employment Barriers**: Limited access to job opportunities and career resources
- **Digital Divide**: Lack of accessible technology for vulnerable populations
- **Resource Fragmentation**: Scattered information across multiple agencies

## 💡 Solution

Shelter Match provides a unified platform that:

1. **Real-time Shelter Matching**: Connects individuals with available beds using live data
2. **Job Placement Support**: Links users with employment opportunities and career services
3. **Multilingual Support**: Available in English and Spanish to serve LA's diverse population
4. **Mobile-First Design**: Optimized for smartphones, the primary device for many users
5. **Accessibility Features**: Inclusive design for users with disabilities
6. **Emergency Resources**: Quick access to crisis hotlines and emergency services

## 🛠️ Technical Implementation

### Frontend Technologies
- **React 18**: Modern UI framework with hooks and context
- **Material-UI**: Professional design system with accessibility features
- **Progressive Web App (PWA)**: Installable app with offline capabilities
- **Google Maps Integration**: Interactive maps for shelter locations

### Backend Technologies
- **Node.js & Express**: RESTful API server

- **RESTful APIs**: Standardized data exchange
